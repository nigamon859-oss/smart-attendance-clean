Install Native Mobile App

You can install this app directly onto your Android, iPhone, or iPad home screen for full offline access, alarms, and full-screen experience.

A complete Flutter/Android project harness is bundled in the repository. Run flutter build apk --release to produce a signed .apk for direct side-loading!
